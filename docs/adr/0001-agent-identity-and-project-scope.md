# ADR 0001：区分 Agent 个人身份与项目群角色

- 状态：已采纳
- 日期：2026-10-08

## 背景

Agent 可加入多个项目群。把“群主/worker”、工作目录或群内分工写入个人 Prompt，会让同一个 Agent 在私聊和其他群里继续携带错误身份；成员模型调整也可能意外改变个人默认。

## 决策

- Agent 个人 Prompt 只描述跨场景稳定的人设和能力。
- 项目群以独立群规则定义群级目标、约束与协作方式；职责写在每个群的成员关系上。
- 群主身份属于项目群成员关系，只在该群有效。
- Agent 保留个人引擎、模型和思考默认；群成员关系可分别覆盖模型和思考程度，未覆盖时继承个人值。
- Jeff 工具能力不按 Agent 身份、名称或分类限制；工具仍校验真实调用者、会话和资源作用域。

## 结果

同一 Agent 可以在一个群协调、在另一个群执行，并在私聊保留个人身份。群成员配置与群规则需要随结构化项目数据同步；历史群消息继续保留为历史记录，不会改写。
