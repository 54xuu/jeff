# ADR 0003：浏览器接管记录与登录态仅保存在本机

- 状态：已采纳
- 日期：2026-10-09

## 背景

浏览器接管需要在应用重启后记住原任务并等待用户明确交还，同时复用用户已经登录的网站会话。同步任务记录或浏览器凭据会把会话身份与认证状态暴露到其他设备；仅保存“网站登录页”也可能携带 OAuth 回调参数。

## 决策

- 当前人工接管记录只保存在 Jeff 本机数据库的 KV 中，不进入 WebDAV 同步、手机消息正文或备份包。
- 接管记录仅含本机原会话 ID、任务来源与标签、站点来源、接管原因、时间和等待/续接状态。站点 URL 只保存 origin；认证 query 与 fragment 不写入记录。
- 页面正文、DOM、Cookie、表单输入、密码、验证码和认证令牌不写入接管记录或工具状态。用户接管期间不向 AI 回传页面截图、内容和控制台现场。
- 网站登录态由 Electron 的 `persist:jeff-browser` 分区在本机管理，不由 Jeff 导出、复制、同步或备份；会话是否跨重启有效取决于网站下发 Cookie 的持久期。
- 只持久化当前等待用户的接管，不持久化其余等待使用浏览器的运行时队列。进程重启后不会自动恢复 AI 或重新执行任务；需要用户明确交还或取消。

## 结果

该设计支持同一台电脑的登录态复用和任务等待恢复，同时不建立跨设备登录凭据副本。站点会话可能过期或使用仅会话 Cookie；这时用户需要重新登录，Jeff 不承诺所有网站都能在重启后免验证。
