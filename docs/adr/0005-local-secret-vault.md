# ADR 0005：密码库的值只留在本机，启动时注入引擎

- 状态：已采纳
- 日期：2026-10-10

## 背景

技能脚本依赖 API key、token 和账号密码。把它们写进系统环境变量后，每次查版本还要打开「关于」，也说不清哪些值是给 Jeff 用的。

## 决策

- 窗口标题显示 `Jeff v<版本>`，版本只取 `APP_VERSION`。
- 设置 → 密码保存变量名、值、备注和启用状态。系统钥匙串可用时用 Electron `safeStorage` 加密；Linux 的 `basic_text` 视为不可用，降级明文并在页面说明。
- 已启用条目在 sidecar 和外部引擎启动时注入，并覆盖系统同名变量。保留名（`PATH`、`HOME`、`LD_*`、`ELECTRON_*`、`JEFF_*`、`XDG_*`、`OPENCODE_*` 等）拒绝写入。
- 修改后不自动重启引擎。页面提示需要重启，并由用户确认；有进行中的对话或定时任务时先说明会被打断。
- 同步只包含变量名、备注、启用状态和删除墓碑。其他设备显示「待填写」，不接收值或密文。
- 不提供模型工具读写密码库。聊天消息、调试日志和 sidecar 日志会替换长度不少于 8 的精确值。这不能阻止模型执行命令后把值发给模型服务。

## 结果

凭据有一个本机入口，技能不再依赖用户事先导出的系统环境变量。手机遥控不能读写这些通道。
