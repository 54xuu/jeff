# Jeff 多执行引擎

从 1.12.0 起，每个智能体可以选择 OpenCode、Codex CLI、Cursor CLI 或 Claude Code。OpenCode 是默认引擎，随安装包提供；原有供应商、模型、聊天历史与定时任务保持兼容。

## 配置

1. 在电脑上安装、登录外部 CLI，并确保它能在终端中完成一次真实请求。
2. 打开「设置 → 引擎服务」，查看检测到的路径、版本与协议状态。自动检测找不到时填写可执行文件的绝对路径；留空保存恢复自动检测。路径只保存在这台电脑。
3. 打开智能体资料，选择执行引擎。外部模型留空沿用 CLI 默认；Codex/Cursor 可读取模型列表，也可手动填写模型 ID；Claude 使用手动输入。
4. 在聊天中发送明确的测试消息。检测读取版本和帮助信息，不调用模型，也不能证明账号订阅仍有效。

手机连接电脑后，在聊天右上角「更多 → 执行引擎与模型」中选择智能体、引擎、模型与思考档位。CLI 始终在所连接的电脑上执行。手机可以读取状态、修改智能体配置，不能修改电脑可执行文件路径。

## 会话与协作

切换智能体的引擎会新建会话。旧会话保留原引擎与原生会话 ID，在聊天记录中激活后沿原引擎续接；聊天顶栏与输入框上方展示实际引擎。历史会话与当前智能体配置不同的时候，沿用该会话最近的外部模型和思考配置。

项目群各成员可以使用不同引擎。私聊、群话题中的每个成员、每个定时任务和子任务分别持有会话，定时执行不会切换用户正在看的私聊。工具桥的身份由服务端会话绑定决定，模型不能通过传入身份字段切换调用者。

引擎选择、模型与思考档位随智能体双向同步。旧客户端缺少引擎字段时保留已有值；新智能体默认 OpenCode。可执行文件路径、登录凭据、原生会话和外部引擎历史只留在当前电脑。

## 能力与限制

| 能力 | OpenCode | Codex | Cursor | Claude |
|---|---|---|---|---|
| 图片输入 | 支持 | 支持 | 当前接入不支持 | 支持 |
| 思考档位 | 原有模型档位 | 按 CLI 模型支持 | 跟随 CLI | 按 CLI 模型支持 |
| Jeff 上下文用量/手动压缩 | 支持 | 暂不支持 | 暂不支持 | 暂不支持 |
| 小杰与医护助手的专属禁用规则 | 支持 | 禁止选择 | 禁止选择 | 禁止选择 |

不支持的输入会明确报错，不会静默丢弃图片、思考档位，也不会伪造上下文统计。CLI 原生的自动上下文管理仍由它自身执行。模型不支持所选档位时，会返回其错误。

运行配置存放在 Jeff 数据目录的 `engines/<engine>/<Jeff 会话 ID>/` 中，不修改用户全局配置或工作区文件。模型连接和认证配置按白名单复制到私有目录，文件权限限制为当前用户；会话续接需要这些本机数据。不要把这个目录上传到公共仓库。Jeff 提供规则、身份、记忆、`~/.agents/skills` 技能清单和已启用插件/设置中的 MCP。Codex 原生插件与自动技能目录发现关闭，Claude 禁用自动发现，通过私有文件显式注入身份规则并使用严格 MCP 列表，Cursor 使用隔离配置与运行目录。

默认自动执行；小杰、智慧病房分类和医护助手只能使用 OpenCode，避免外部引擎绕过现有文件/工具禁用规则。普通智能体的 Jeff 管理工具禁用仍由会话 MCP 服务端实施。

停止或超时会清理本轮进程组（Linux）或进程树（Windows）。必须收到协议成功结束事件才算完成；失败后 Jeff 不自动重发、不切换引擎。异常中断之前已经执行的工具或文件操作不会自动回滚。

## 接入协议

- [Codex app-server](https://learn.chatgpt.com/docs/app-server)：stdio RPC，thread/start、thread/resume、turn/start 和 turn/interrupt。
- [Cursor 输出格式](https://cursor.com/docs/cli/reference/output-format)：非交互 stream-json，显式 resume 会话，增量与最终 flush 对账。
- [Claude Code 无界面运行](https://code.claude.com/docs/en/headless)：stream-json 输入/输出、增量消息与 resume。

不包含 CLI 自动安装、升级、登录管理，不增加第二种 OpenCode 配置模式，也不部署 relay。

## 手机绑定提示

手机扫码或粘贴绑定码后，会显示正在连接、等待电脑确认、安全连接三个阶段。等待确认时，手机明确显示电脑名称、6 位安全码，并提示在电脑 Jeff 弹窗中点击「确认绑定」。桌面收到请求后显示通知，并在后台闪烁任务栏；开启提示音时会响铃。绑定不会自动批准。

旧 Android WebView 不支持 Unicode 正则时，代码块保留原文与复制按钮，使用普通代码显示；链接和 GFM 表格正常保留。新设备继续提供语法高亮。Windows 支持 npm cmd 启动器和 Cursor 官方版本目录启动器，不把提示词交给 shell 解析。

## 自动记忆分流与记忆界面

对 Jeff 说「记住…」，`jeff_memory` 会按内容和范围保存：

- 密钥、密码、令牌和用户要求保密的内容进入本机记忆，带 `[私有]` 标记；不进入 WebDAV 同步，也不写公开规则。模型标记为公开时，凭据检测仍优先执行。个人隐私可由模型明确标记 `privacy=private`。
- 公开偏好、长期事实和约定写入 AGENTS.md。跨项目通用的内容写 Jeff 数据目录下的全局 `AGENTS.md`；项目内容写 `agents-md/<项目ID>.md`，仅注入该项目群。群聊和群自省默认使用当前项目范围。
- AGENTS.md 中的手工内容保留，自动内容写入带注释的管理区块。`list/replace/remove` 同时管理本范围记忆和自动规则。原有记忆保留，不做猜测性批量搬迁。

「设置 → 记忆」支持搜索智能体和项目群、筛选范围，范围列表与规则列表独立滚动；切换前提示未保存修改。Android「我 → 记忆与公开规则」经加密连接查看和编辑电脑上的内容，带搜索及未保存保护。

本机记忆是权限受限的明文 Markdown，未宣称加密保险库。私有含义是本机保存、不参与配置同步；所选智能体/项目的模型仍会收到该范围记忆。旧版已经上传的凭据不会因此从远端备份历史中自动消失，应自行清理已有远端副本。记忆工具的诊断日志隐藏参数和返回内容；历史对话及引擎原生会话仍可能保留用户输入。
