# 双机自动部署与真机验收

日期：2026-10-07

## 目标与流程

入口为 `npm run deploy:windows -- --target win11 --android auto --suite <测试集>`。命令必须指定 `deploy/suites/` 中的具名测试集；先完成 Ubuntu 本地回归，构建 Linux/Windows 桌面安装包及签名 Android release/test APK，在 Ubuntu 的 `jeff` AVD 安装本次 APK 并运行 instrumentation。AVD 通过后，Windows 端按 USB serial、`192.168.3.121:5555` 的顺序选设备；自动模式下没有真机时保留模拟器通过、真机待验收的状态。

上传前生成包含版本、提交号、文件大小与 SHA-256 的清单。Windows worker 再次核验哈希后，通过独立提权任务静默安装同范围的 NSIS 包，启动已安装的 Jeff 并使用隔离 home / Electron 数据目录运行具名桌面断言。证据保存在 `.tmp/deploy/<运行编号>/`。

Windows 真机在 instrumentation 中明确断连时，Windows worker 保存设备状态和错误，Ubuntu 重跑整套 AVD instrumentation；签名、安装或仍在线设备上的功能断言失败不会被降级为成功。

## 首次配置

Windows 初始化脚本位于 `deploy/windows/Configure-Windows.ps1`，详细步骤见 `deploy/windows/README.md`。它配置限定 Ubuntu 来源 IP 的 SSH 防火墙规则、公钥认证、登录用户桌面验收 worker 及独立提权安装任务。Ubuntu 的主机别名与运行配置放 `.tmp/deploy/`，不入库。
