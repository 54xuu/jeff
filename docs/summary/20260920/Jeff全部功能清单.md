# Jeff 全部功能清单（对照代码）

- 日期：2026-09-20
- 范围：仓库当前代码（`APP_VERSION` = `1.8.20`）
- 方法：扫 `packages/core`（IPC / 工具 / DB / 编排）与 `apps/desktop`（导航 / 设置 / 聊天 / 浏览器）

Jeff 是个人「开发 + 项目管理」agent 桌面应用：微信式心智模型——**智能体 = 好友、项目群 = 微信群、小杰 = 管家**。引擎是隔离的 opencode sidecar，壳是 Electron + React；平台为 Windows x64 + Linux x64。

## 6. 小杰能代操 vs 必须去设置

| 小杰能做（工具） | 必须去设置 / 菜单 |
|------------------|-------------------|
| 智能体 CRUD（含模型、思考、分类） | 模型供应商与 API Key |
| 项目群建改/成员/解散 | MCP 连接器导入/启停 |
| 任务 CRUD | WebDAV 同步与 skills/插件目录备份 |
| 定时任务 CRUD | 主题 / 引擎重启（菜单「重启 Jeff」可整应用重开） |
| 插件开发（默认停用；本地命令型不能由它启用） | |
| 记忆读写、历史会话搜索 | |
| 内置浏览器操作（但不能把网页写成文件） | |

其它智能体**没有** `jeff_agent_*` / `jeff_project_*` / `jeff_task_*` / `jeff_cron_*` / `jeff_plugin_*`。群主额外有 `jeff_delegate`。任意智能体都有 `jeff_memory`、`jeff_session_search`、`jeff_browser_*`、`jeff_plugin_list`。普通智能体带编码/文件/MCP/技能工具。

特例：分类为「智慧病房」或名为「医护助手」的智能体禁 `bash/edit/write/patch/task/read`，必须走插件 MCP。

## 7. 定时任务

| 功能 | 说明 | 入口 |
|------|------|------|
| 到点发消息 | 向某智能体私聊或某项目群发 prompt 并让对方执行/回复 | 「定时」页；菜单 `Ctrl/Cmd+Shift+T`；小杰 |
| 5 段 cron | 本机时区「分 时 日 月 周」；模板一键填充；人性化描述 + 下次触发时间 | 新建/编辑弹窗 |
| 错过策略 | `catchup` 开机补跑最后一次；`skip` 直接跳过 | 任务字段 |
| 立即执行 / 启停 / 编辑 / 软删除 | 卡片操作 | 定时页 |
| 运行历史 | running/ok/failed/missed/skipped + 耗时 + 失败原因；失败不自动重试 | 卡片展开 |
| 会话隔离 | 每任务独立私聊 session 或独立群话题，不污染用户窗口；同任务复用自己那条 | 调度器 |
| 并发 | 上限 2；同群因共享工作空间仍串行；上一轮未完再触发则 skip | 调度器 |
| 目标删除自动停用 | 智能体/群没了，任务停用并记原因 | 调度器 |
| 同步 | 定义随 WebDAV（LWW + 墓碑）；`next_run_at` 本机重算；运行历史不同步 | 设置 → 同步 |

工具（仅小杰）：`jeff_cron_create/list/update/delete`。

## 9. 内置浏览器

| 功能 | 说明 | 入口 |
|------|------|------|
| 右侧独立面板 | 人与智能体操作同一页面；关面板即销毁 webview | 导航地球；菜单 `Ctrl/Cmd+Shift+B`；agent 工具自动唤起；插件首页 |
| 工具栏 | 后退/前进/刷新/地址栏/分辨率/系统浏览器打开/关闭 | 面板顶栏 |
| 地址栏 | 省略协议自动补 `https://`；只允许 http(s)；权限请求默认拒绝 | 地址栏 |
| 新窗口原地打开 | `target=_blank` / `window.open` 在当前页打开，不弹新标签 | webview |

| 记住上次 URL | 本机 localStorage | 面板 |
