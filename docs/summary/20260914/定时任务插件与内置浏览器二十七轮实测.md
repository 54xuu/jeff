## 一、修掉的产品 bug（都有回归测试兜住）

| # | 现象（谁发现的） | 根因 | 修法 |
|---|------------------|------|------|
| 1 | **`navigate` 报假标题**：agent 说「已打开 http://127.0.0.1:46765」——它把地址当成页面标题 | webview 在页面还没标题时把 URL 当 title 返回，工具直接透传 | `navigateTo` 增加 bounded `settle()`（优先读页面 `document.title`，最多等 4s，等不到就返回空标题而不是假标题） |
| 2 | **`navigate` 对打不开的页面回 ok:true**（v18 封闭测试发现） | `loadURL()` 在「连接被拒」这类失败上仍会 resolve——失败是 `did-fail-load` **异步**报的 | 渲染层记下主文档失败（带 URL），`navigate` 结束前核对「失败的地址 = 本次要开的地址」则抛错；URL 比对避免把别的导航的失败算到这次头上 |
| 3 | **图片/脚本/接口 404 完全采集不到**：`jeff_browser_get_console` 空 | Electron 的 `console-message` 只承载 Console API 调用与未捕获异常，**子资源加载失败不走** | 主进程在该面板专属分区（`persist:jeff-browser`）挂 `webRequest.onCompleted/onErrorOccurred`，失败变成 `level:'load'` 条目经 IPC 投进面板同一份缓冲（应用自身流量不受影响） |
| 4 | **小杰改定时任务会静默停用**：只让改时间，任务却被停用、错过策略被改、名字被清空 | 模型会把「没打算改的字段」补成空串，而 `'' !== undefined` → `enabled:''` 当成 false、`name:''` 清空 | cron 工具统一「空串 = 未提供」，无字段可改时明确报错（真模型复测：R5/R23 只改一个字段，其余原样） |
| 5 | **小杰根本没法给智能体分组** | 实现（`adminTools`）支持 `category`，但模型看得到的**工具定义漏了它**——模型永远传不进来（与 v1.8.2 插件工具同一类 bug） | 定义补 `category`；同时把 admin/project/task 三处 update 一起按「空串 = 未提供」加固（真模型复测 R20/R21/R22 全绿） |
| 6 | **agent 导航被旧地址的失败污染**（live13 R13）：agent 打开可用地址却拿到 `ERR_CONNECTION_REFUSED` | 面板被唤起时会恢复「上次访问的地址」（常常已经不可用），它的加载失败与 agent 的导航抢时序 | ① agent 触发唤起时用它的目标地址当起始地址、不恢复旧地址；② 失败记录带上 URL，只算「同一页」的失败 |
| 7 | **非法枚举值报内部错误**：`jeff_task_update status:'nope'` 抛 `Cannot read properties of undefined (reading 'id')` | repo 对非法值返回 `undefined`，工具直接读 `row.id` | 调用 repo 前校验 status/priority，报「status 非法：nope（可用：todo/…）」 |

## 二、补齐的两个能力（此前只有文档/需求，没有实现）

- **`jeff_browser_upload`**：把本机文件放进页面 `<input type=file>`（主进程读盘 → base64 → 渲染层用
  `DataTransfer` 造 `File` 设置 `input.files`），明确提示「只是选中了，提交还要点提交按钮」；
  拒绝非绝对路径、空文件、>8MB、非 file 输入框。
- **`jeff_browser_get_console`**：读当前页面的错误现场（`console.error/warn`、未捕获异常、主文档加载失败、
  子资源加载失败），支持 `level` 过滤与 `limit`；面板工具栏红点角标与它读同一份缓冲（导航时清空）。
- 顺手补上 `jeff_browser_type` 对 `<select>` 的支持（否则「提交表单」在带下拉框的表单上走不通，
  真机行为是 `Illegal invocation`）；选项不匹配时把可选项列给模型。

## 三、27 轮覆盖（真模型）

**定时任务（R1–R5）**
- R1 私聊 catchup：错过后补跑一次、agent 真回复、`cron_run` 记 `ok`+`is_catchup`、下次时间已重排
- R2 群聊：护士长点名 → 成员回合 → 总结（群里 ≥2 轮智能体发言）
- R3 定时页 GUI 全流程：新建（描述/下次时间预览）→ 编辑 → 停用/启用 → 立即执行 → 历史 → 删除（确认弹窗 + 墓碑）
- R4 边界：`skip` 只记 missed 不跑；目标智能体被删 → 任务自动停用 + `failed` 写明「目标智能体已被删除」；非法表达式拦住保存
- R5 小杰建任务 → 只改时间 → 其余字段不被空值抹掉（bug #4 的真模型回归）

**插件（R6–R12）**
- R6 坏清单（坏 JSON / 指令缺 `/` / homepage 协议不对）带错误展示且开关禁用；目录导入
- R7 启用 → `plugin-*` 注入 `settings:mcp` → 引擎重启 → `/` 指令 → **agent 真调到插件 MCP 工具**（服务端收到调用）→ 停用摘除
- R8 密钥：`${SECRET}` 占位符在注入时替换为真值，**服务端从请求头里读到了密钥**
- R9 本地命令型插件：小杰调 enable 被拒（安全闸）→ 人在插件页点开关启用 → agent 真调到 stdio MCP（子进程写下取证文件）
- R10 插件首页 → 内置浏览器打开
- R11 插件备份/恢复（真实 WebDAV 沙箱）：远端清单可取、插件文件本体可取；本地目录删掉后从备份恢复、恢复前有本地快照
- R12 小杰对话式开发插件：平铺参数落盘（`mcp_url`/`files`/emoji）→ 只改一个字段不抹其它 → 启用 → 真调通

**内置浏览器（R13–R18）**
- R13 agent 打开页面并读出标记（查看）
- R14 **三步向导**：填姓名 → 下一步 → 选病区 + 备注 → 下一步 → 勾选 → 提交，**服务端收到完整表单**（断言字段值）
- R15 **上传本机文件**：服务端收到文件名（中文名按 UTF-8 正确解码）与文件内容（含中文字节）
- R16 **分析错误**：读到 `console.error` 标记、未捕获异常、资源 404
- R17 负路径：打不开的地址明确失败、不挂死
- R18 插件 + 浏览器联动：查插件 → 用内置浏览器打开其首页

**小杰专场（R20–R27，含「权限边界」）**
- R20 智能体：建（头像/思考/分组真落库）→ 改 → 列表 → 删；**改不了自己**（内置管家身份不可改）
- R21 项目群：建群（群主 + 成员）→ 改名/工作空间 → 加/移成员 → 解散（软删）
- R22 任务：建任务（`JEF-n`）→ 状态流转 todo→in_progress→done → 列表 → 删
- R23 定时任务：列表 → 停用（其余字段不变）→ 启用 → 删除（删除是软删；「不再运行」的判据是调度器取数条件 `deleted_at IS NULL AND enabled = 1`）
- R24 插件：`read` 看清单与附带文件 → 改简介 → 删除（目录与启用状态一起清）
- R25 小杰用内置浏览器：打开页面 → 读内容 → 读错误（含资源 404）
- R26 **权限边界**：小杰的 agent 定义里 `bash/edit/write/patch: false`（真去改盘上普通文件：文件未变、也没有出现文件/命令工具调用）；普通智能体的定义里管家工具是 `false`（让资讯助手去建定时任务：DB 里没多出任务）
- R27 记忆与会话检索：写 `scope:'user'` 记忆 → 落盘 `memory/USER.md`；`jeff_session_search` 搜到历史暗号
- R19 顺带全功能回归：通讯录分组 / 私聊一轮 / 暗亮主题截图

## 四、测试台的两个关键技巧（下次沿用）

1. **无需模型也能覆盖真链路**：`<home>/oc-home/config/opencode/plugin/jeff-bridge.js` 里有 `BASE` 与 `TOKEN`，
   测试进程直接 `POST /tools/<name>` 就是「真工具 + 真跨进程」，用它做了 v18 的封闭套件
   （定时任务边界 / 插件校验 / 浏览器点击·填表·上传·错误分析 / 面板唤起竞争）。
2. **验收必须落在服务端事实**：表单任务断言**服务端收到的字段**、上传断言**服务端收到的字节**、
   插件断言**MCP 服务端收到的调用与请求头**、定时任务断言 **DB 的运行记录**——只看 DOM/回复会漏掉
   「模型说成功了但其实没落地」这类问题（R26 的「绕道」就是这么暴露的）。

## 五、已知边界（本轮未做，明确不装）

- 任务（`jeff_task_*`）**还没有界面**：现有入口只有小杰工具与 DB（路线图里的「任务看板」仍是缺口）。
- 浏览器只采集**当前页**的错误；`window.onerror` 之外的老式 `onerror` 赋值、跨域 iframe 内部错误不采集。
- 上传走 `DataTransfer` 造 `File`（webview 没有暴露「设置真实文件路径」），服务端收到的是同一份字节，
  但 `input.files[0].path` 为空（依赖该字段的站点除外）。
- 小杰的删除类操作按产品约定「必须先跟用户确认」，测试里都由用户显式授权后执行。
