## 二、用户反馈的 4 个问题与修复

### 1. MCP 无法编辑和重启 → 已修复

- 现状：`McpSettings.tsx` 只有导入 JSON / 启用禁用 / 删除 / 探测，没有单个服务的「编辑」，页面上也没有「重启引擎」按钮（提示文案写着"保存后重启引擎生效"，但重启只能去引擎服务页）。
- 修复（`apps/desktop/src/renderer/src/components/settings/McpSettings.tsx`）：
  - 每个服务行新增「编辑」按钮：打开对话框并**预填该服务当前 JSON**（`{"mcpServers":{…}}` 包裹），支持解析校验后保存；支持**改名**（新名写入、旧名移除）。原导入弹窗与编辑弹窗合并为共用的 `ServerJsonDialog`。
  - 工具栏新增「重启引擎」按钮（`sidecar:restart`），带「重启中…」态。
  - 顺带把 `IPC.mcpSave` 的 contract 类型补上遗漏的 `environment` 字段（运行时本来就透传，仅类型缺失）。

### 2. mysql-test MCP 报错（Windows 正常、Linux 报错）→ 根因修复

- 排查：`@benborla29/mcp-server-mysql` 在本机 Linux 直连探测 **347ms 即连上**（`mysql-test_mysql_query` 可用），包本身没问题；MySQL 主机 192.168.3.249 网络连通。
- 根因：**GUI（桌面图标）启动的 Electron 继承的 PATH 不含 nvm 的 bin**（本机 node/npx 装在 `~/.nvm/versions/node/v24.18.0/bin`），opencode sidecar 拉起 MCP local 命令 `npx …` 时找不到可执行文件；Windows 的 npx 在系统 PATH 上所以正常。终端启动 Jeff 时 PATH 正常，所以"时好时坏"。
- 修复：新增 `packages/core/src/util/nodePath.ts` 的 `augmentedPath()`——把 nvm（多版本取最新）、`~/.local/bin`、`~/.volta/bin`、`~/.cargo/bin`、`/usr/local/bin`（Windows 另加 `%APPDATA%\npm`）中实际存在的目录**前置**进 PATH：
  - `sidecar/manager.ts` 的 `sidecarEnv()`：sidecar 及其拉起的所有 MCP 子进程都受益；
  - `mcp/probe.ts` 的 `minimalEnv()`：设置页探测与真实引擎行为一致。
- 验证：E2E R4 中 `mysql-test_mysql_query` 真实调用完成，`SHOW DATABASES` 返回 13 个库；设置页探测显示「已连接 · 1 个工具」（亮/暗色截图均确认）。

### 3. 能否搜索 → 结论 + 默认指引

- 结论：opencode 内置 `websearch` 工具依赖搜索服务密钥（Exa 等），Jeff 未配置该密钥，直接调用会失败；本机已安装 `byted-web-search` 技能（火山引擎豆包搜索，走 `WEB_SEARCH_API_KEY` 环境变量，`~/.agents/skills` 已挂载），实测脚本可用（944ms 返回结果）。
- 修复（`packages/core/src/index.ts`）：新增 `WEB_SEARCH_GUIDE` 常量并在 `buildMemorySystem` **每轮注入**（私聊/群聊/委派都走它）：联网搜索优先用 byted-web-search 技能，不要用内置 websearch；缺凭证时引导用户配置 `WEB_SEARCH_API_KEY`。
- 验证：E2E R5 中模型确实经 `skill` 工具走了豆包搜索并给出结果链接。

### 4. opencode 引擎是否要更新 → 已升级 1.18.26 → 1.18.30

- 最新版为 1.18.30。升级方式：改 `apps/desktop/scripts/fetch-opencode.mjs` 的默认 VERSION 与 `.github/workflows/release.yml` 的 `OPENCODE_VERSION`，`node scripts/fetch-opencode.mjs 1.18.30 linux-x64 windows-x64` 重新下载（二进制在 gitignore 的 `apps/desktop/resources/oc-bin/`，不入库）。
- 全部单测、mock UI E2E、8 轮真实模型 E2E 均在 1.18.30 上通过，无回归。
