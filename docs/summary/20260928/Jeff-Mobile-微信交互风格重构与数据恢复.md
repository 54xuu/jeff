# Jeff Mobile 微信交互风格重构与数据恢复

2026-09-28。针对用户反馈的「apk 重新安装后没有数据了但实际上已经绑定了、列表和聊天窗口完全不像一个产品就像一个 demo、聊天界面里一些工具调用和思考模式无法看到」三大核心痛点，深度参考微信移动端样式和交互逻辑，对 `apps/mobile` 与原生 Android 插件层进行彻底重构与升级。

---

## 一、核心问题诊断与解决

### 1. APK 重新安装后数据丢失与已绑定失效
- **根因分析**：
  1. 手机端私钥凭证原先仅保存在 Web 的 `localStorage` 中；当 APK 卸载重装或应用存储被清理时，`localStorage` 清空，应用冷启动时随机生成全新的密钥对与 `appId`，导致中转站与电脑端仍保留旧绑定而手机端无法识别。
  2. `session.ts` 中的 `url`、`pin`、`desktops`、`activeId` 等配对凭证之前仅驻留于内存变量，从未持久化。启动 `boot()` 时也未尝试自动连接，导致冷启动后 `bound` 恒为 `false`，界面直接落回扫码绑定页。
- **解决方案**：
  1. **原生双层持久化存储**：在 `apps/mobile/android/app/src/main/java/app/jeff/mobile/JeffSpikePlugin.kt` 中引入原生持久化接口 `getPersistedProfile` 与 `savePersistedProfile`：
     - 主层使用 Android 原生 `SharedPreferences("jeff_profile")` 存储完整 Profile（包含身份密钥、中转站地址与 PIN、已绑定电脑列表及活动电脑 ID）。
     - 备用层将凭据镜像写入 Android `context.getExternalFilesDir(null)` 与外部公共 Downloads 目录下的加密配置备份中，即便应用卸载重新安装，也能自动恢复身份凭证。
  2. **冷启动自动重连机制**：在 `apps/mobile/src/session.ts` 的 `PhoneLink` 中加入 `init()` 与 `persistProfile()` 生命周期钩子。应用启动时先从原生持久层恢复凭据，自动与中转站建立加密 WebSocket 连接，并自动吸纳已绑定的电脑；在每次配对、切换活跃电脑或解绑时实时持久化。
  3. **双重缓存离线优先渲染**：`App.tsx` 启动时首先从本地持久化中快速加载并渲染智能体和群聊列表，彻底杜绝白屏与空列表现象，同时在后台静默发起远端 RPC 同步刷新。

### 2. 界面与交互全面重构为微信设计系统（消除 Demo 感）
- **微信色彩与视觉规范**（`apps/mobile/src/styles.css`）：
  - **亮色模式**：遵循微信经典底色 `#ededed`、聊天背景 `#ededed`、卡片与会话项底色 `#ffffff`、主色调微信生机绿 `#07c160`、微信用户气泡经典绿 `#95ec69`、正文微灰黑 `#191919`、次级灰文本 `#888888`。
  - **暗色模式**：遵循微信深黑规范：底色 `#111111`、卡片底色 `#191919`、对方气泡深灰 `#262626`、我方气泡深墨绿 `#2b5a3e`。
  - **组件质感**：移除所有生硬突兀的浮动描边卡片，会话列表采用微信经典的白底连续无缝列表，底部分割线精确从 76px（头像后）起步，带微信原生按压高亮反馈 `#d9d9d9`。
- **微信标准底部 TabBar**：
  - 新增底部双标签导航：「消息」与「我」，采用微信 SVG 图标与 10.5px 紧凑文字，高亮态采用微信生机绿。
  - 在「我」页面中呈现微信个人主页式排版，收拢「已绑定电脑列表」、「扫码/粘贴绑定操作」以及「后台保活与锁屏安全设置」。
- **微信聊天窗口交互**：
  - **顶栏**：微信标准左侧 `‹ 返回`、中间居中对话标题（群聊自动带专属群徽标）、右侧功能扩展入口。
  - **气泡与箭头**：发送方与接收方均带微信原生指向头像的小三角箭头，排版紧凑舒适。
  - **底栏输入框（Composer）**：
    - 左侧微信圆形加号图标。
    - 中间白底单行微圆角矩形输入框（4px border-radius）。
    - 交互状态联动：输入框存在文本时右侧动态浮出微信经典绿色「发送」按钮；流式输出阶段显示红色「停止」按钮；输入框为空时保留加号拓展功能。
  - **加号拓展面板**：微信 4 列宫格白底圆角图标（相册、新建会话、切换会话、工作空间），支持就地展开历史会话抽屉。
- **Android 返回手势与物理返回键拦截**：
  - 加号面板打开时按返回键先关闭面板；
  - 聊天页按返回键平滑退回到会话列表；
  - 「我」Tab 下按返回键退回「消息」Tab；
  - 主列表顶层按返回键调用 `moveTaskToBack` 将应用转入后台保活，不杀掉进程。

### 3. 思考模式（Reasoning）与工具调用（Tool Calls）组件化展示
- **思考模式组件（`ReasoningView`）**：
  - 针对带有 `reasoning` 或流式思考中的消息，在对方气泡顶部内嵌圆角思考卡片。
  - 顶部栏呈现灯泡图标、思考状态（流式阶段带有呼吸动态绿点 `思考中…`，完成后显示 `思考过程`）以及最新一行推理内容的单行预览摘要与展开箭头。
  - 点击可就地展开查看完整思考推导文本，支持横向滚动与复制，完全不再有「思考过程被吃掉」的问题。
- **工具调用组件（`ToolsView`）**：
  - 呈现扳手图标、工具调用总数统计、状态 Tag（`运行中…` / `执行失败` / `完成`）与折叠展开箭头。
  - 展开后清晰展示调用的每一个工具名称、执行状态；若存在 `output` 或 `error`，提供专属格式化代码块，方便随时洞察智能体的背后动作。
