# 群资料整理与「会话即话题」

> 日期：2026-09-07 · 版本：v1.4.0 → v1.5.0 → **v1.6.0**（纠偏）

## 背景（简）

1.5.0 误把「按成员的 opencode 会话」当成任务；1.6.0 改为**项目级 thread**：界面扁平群聊历史，内部仍按 agent 路由。详见下文「功能纪要」。

---

## 打包与发版（重点）

### 约定（AGENTS.md）

1. 三处 `package.json` 版本必须一致（根 / `packages/core` / `apps/desktop`）。
2. 功能重构升 **MINOR** → 本批 **1.5.0 → 1.6.0**。
3. 产物目录 `apps/desktop/release/` 已在 `.gitignore`，**勿提交** deb / AppImage / exe / `*-unpacked`。
4. 发版后应本机安装验证，并在「设置 → 关于」确认版本号。

### 本机 Linux 包

```bash
# 仓库根目录
npm run package:linux
# 产物：
#   apps/desktop/release/jeff-desktop_1.6.0_amd64.deb
#   apps/desktop/release/Jeff-1.6.0.AppImage

sudo dpkg -i apps/desktop/release/jeff-desktop_1.6.0_amd64.deb
# 退出并重开 Jeff → 设置 → 关于 → 确认 1.6.0
```

本次结果：✅ 本机已打出 `jeff-desktop_1.6.0_amd64.deb` / `Jeff-1.6.0.AppImage`（`dpkg` 需本机密码，未在自动化里执行）。

### 本机 Windows 包（可选；本环境失败原因）

```bash
npm run package:win
# 期望产物：apps/desktop/release/jeff-Setup-1.6.0.exe
```

- electron-builder 在 **Linux 上打 NSIS** 依赖 **wine**（`spawn wine ENOENT`）。
- 无 sudo 无法 `apt install wine64`；中途产生的约 200KB 残缺 exe 已删除，勿当正式安装包。
- 若要本机再打 Win：先 `sudo apt install wine64`（及常见 wine32 依赖），再重跑 `package:win`。

### 推荐：打 tag → GitHub Actions 双平台 Release

工作流：[`.github/workflows/release.yml`](../../.github/workflows/release.yml)

| 触发 | 行为 |
|------|------|
| `push` / PR → `main` | 仅 **test**（tsc + 单测） |
| 推送 **`v*` tag** | test 通过后 matrix：**ubuntu** 打 Linux，**windows** 打 Win，并上传 GitHub Releases |

```bash
# 代码已合入 main、版本已 bump 后
git tag -a v1.6.0 -m "v1.6.0: 群聊项目级会话话题"
git push origin v1.6.0
# 或：git push origin HEAD && git push origin v1.6.0
```

CI 步骤摘要：

1. `npm ci` → 按平台 `fetch-opencode.mjs`（linux-x64 / windows-x64）
2. `electron-vite build` → `electron-builder --linux|--win --x64`
3. 上传到同一 Release：
   - Linux：`Jeff-*.AppImage`、`jeff-desktop_*_amd64.deb`
   - Windows：`jeff-Setup-*.exe`（NSIS，`artifactName: jeff-Setup-${version}.${ext}`）

## 功能纪要（v1.6.0）

### 数据模型

| 概念 | 键 / scope |
|------|------------|
| 活跃话题 | kv `group:activeThread:<projectId>` |
| 话题元数据 | kv `group:thread:<projectId>:<threadId>` |
| 消息 | `chat_message.scope = group:<projectId>:<threadId>` |
| 成员引擎会话 | kv `session:group:<projectId>:<threadId>:<agentId>` |

旧 `group:<projectId>` 消息与二元 session 键迁入「默认会话」。

### UI / IPC

- 群资料下段扁平「聊天记录」；顶栏「新会话」清空主窗
- `groupThreadsList` / `New` / `Activate` / `Rename` / `Delete` / `Preview`

### 验证（功能）

| 项 | 结果 |
|----|------|
| tsc / 单测 89 / E2E | ✅ |

### 使用说明

- **新会话**：顶栏 → 主窗清空；旧记录在「群资料 → 聊天记录」
- **继续 / 改名 / 删除**：群资料下段操作
- **改群背景**：群资料简介（注入 system）
