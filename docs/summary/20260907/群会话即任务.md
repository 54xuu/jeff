# 群资料整理与「会话即任务」

> 日期：2026-09-07 · 版本：v1.4.0 → **v1.5.0**

## 背景

1. 群简介本应作为固定项目背景注入群聊 system；编辑区太小，侧边抽屉把设置/成员/看板挤在一起。
2. 看板不再适合：任务应对齐「每个成员下的会话列表」（类似智能体聊天记录）。
3. 所有会话（含历史）应可修改标题；每个会话即一个任务。

## 事实与改动

### 群简介 → system prompt

[`buildBriefing`](../../packages/core/src/orchestrator/group.ts) 原先已注入群简介；本批强化为：

- 固定文案：`项目背景（群简介）：…`
- 空简介仍写入占位：`（未填写，请在群资料补充）`
- 建群弹窗 / 群资料：简介改为多行 `textarea`

### 群抽屉重组（去看板）

[`GroupInfoDrawer.tsx`](../../apps/desktop/src/renderer/src/components/GroupInfoDrawer.tsx)：

- **上段**：群名 / 图标 / 简介 textarea / 工作空间 / 群主 / 成员加减 / 解散
- **下段**：按成员分组的任务会话（当前 / 改名 / 继续 / 删除 /「+ 新任务」）
- 群顶栏「聊天记录」并入此抽屉；按钮改为「群资料」；另加「新任务」（给群主开新会话）
- JEF-n 看板 UI 与任务卡片点击打开看板已去掉；`jeff_task_*` / 任务表仍保留（小杰可后台用）

### 会话改标题

- `OcClient.updateSession` → `PATCH /session/{id}`
- IPC `sessionRename`、`groupNewSession`
- 私聊 [`ChatHistoryDrawer`](../../apps/desktop/src/renderer/src/components/ChatHistoryDrawer.tsx) 与群抽屉均可改名
- 群新会话默认标题：`任务 · {成员} · {月/日 时:分}`

## 使用说明

- **改群背景**：群资料 → 简介多行保存（会注入每位成员任务会话的 system）
- **开任务**：顶栏「新任务」（群主）或群资料里某成员旁「+ 新任务」
- **改任务名**：群资料 / 私聊「聊天记录」里点「改名」或双击标题
