# 群资料整理与「会话即话题」

> 日期：2026-09-07 · 版本：v1.4.0 → v1.5.0 → **v1.6.0**（纠偏）

## 背景

1. 群简介本应作为固定项目背景注入群聊 system；编辑区太小。
2. **1.5.0 误模型**：把「每个成员下的 opencode 会话」当成任务展示——错误。
3. **正确心智**：话题/任务属于整个项目群；界面是一段扁平群聊历史（类微信）；内部仍路由到不同 agent。

## v1.5.0（已纠偏，保留纪要）

- 群简介强化注入 `项目背景（群简介）`；简介改为 textarea；去掉看板 UI
- 会话改标题（`PATCH /session`）；私聊历史可改名
- ~~按成员分组的「任务会话」+「新任务」~~ → 已被 1.6.0 取代

## v1.6.0 纠偏：项目级 thread

### 数据模型

| 概念 | 键 / scope |
|------|------------|
| 活跃话题 | kv `group:activeThread:<projectId>` |
| 话题元数据 | kv `group:thread:<projectId>:<threadId>` |
| 消息 | `chat_message.scope = group:<projectId>:<threadId>` |
| 成员引擎会话 | kv `session:group:<projectId>:<threadId>:<agentId>` |

- 迁移：旧 `group:<projectId>` 消息与 `session:group:<projectId>:<agentId>` 升入「默认会话」
- 不新增 SQL 表；聊天本不同步 WebDAV，迁移仅本机

### UI / IPC

- 群资料抽屉下段：**聊天记录**（扁平列表：标题 / 时间 / 当前 / 改名 / 继续 / 删除 + 预览）
- 顶栏「新会话」→ `groupThreadNew`（清空主窗；旧 thread 仍在历史）
- API：`groupThreadsList` / `groupThreadNew` / `Activate` / `Rename` / `Delete` / `Preview`
- 默认标题：`会话 · {月/日 时:分}`（不再带成员名）

## 使用说明

- **改群背景**：群资料 → 简介多行保存（注入 system）
- **新会话**：顶栏「新会话」→ 主窗清空；旧记录在「群资料 → 聊天记录」
- **继续 / 改名 / 删除**：群资料下段聊天记录操作
- **私聊**：仍用聊天记录抽屉改标题
