# 跨设备同步缺口（v1.7.0）

## 问题

Windows 新装 Jeff 并「立即同步」后，设置（供应商/主题）进来了，但智能体与项目群不出现。用户期望同步智能体配置与项目群资料，不同步历史会话。

## 根因

1. **合并失败被当成空**：`getJsonArray` 把所有 GET 失败（含 500/超时）当成 `[]`，随后 `pushToRemote` 用本机（往往只有小杰）覆盖远端 `agents.json`。
2. **同步后不刷新**：`syncNow` 成功后不 `emit('data-changed')`、不重写 sidecar agent md / MCP 配置，通讯录看起来仍空。
3. **半成功写入**：`applyToLocal` 无事务，settings 先落库、后面失败 →「只有设置同步了」。
4. **配置缺口**：`settings:mcp`、AGENTS.md 根本不进同步包；`workspace_dir` 会把 Linux 路径拷到 Windows。

## 方案（Grill 对齐）

- 修合并与刷新；项目群同步资料/任务，路径按设备保留
- MCP 全量同步；用户级 + 项目级 AGENTS.md（按 projectId 权威副本）
- 记忆继续同步；会话历史不同步；skills 仍手动恢复

## 改动要点

| 文件 | 内容 |
|------|------|
| `packages/core/src/sync/engine.ts` | 404 才当空；事务 apply；MCP；AGENTS.md；忽略远端 workspace_dir |
| `packages/core/src/paths.ts` | `agentsMdDir`（`~/.jeff/agents-md/`） |
| `packages/core/src/index.ts` | sync 成功后刷新 registry/sidecar/UI；AGENTS.md 权威副本；小杰 seed 不无谓顶 updated_at |
| `packages/core/src/tools/memoryTools.ts` + IPC | 记忆写入触发 `data-changed` |
| `SyncSettings.tsx` | 文案说明 MCP/AGENTS.md 与手动 skills |
| `tests/sync.test.ts` | MCP/AGENTS.md、路径保留、GET 500 不回推 |

## 验证

- `npx vitest run tests/sync.test.ts tests/skills-sync.test.ts` 全绿
- 版本三处 `package.json` → **1.7.0**
- 已打 Linux 包：`apps/desktop/release/jeff-desktop_1.7.0_amd64.deb`
- 本机安装需密码：`sudo dpkg -i apps/desktop/release/jeff-desktop_1.7.0_amd64.deb`，然后退出并重开 Jeff，在「设置 → 关于」确认版本

## Windows 侧建议验证

1. 立即同步后通讯录出现智能体、项目群列表刷新
2. 群工作空间路径为空或仍是本机路径（不是 Linux `/home/...`）
3. MCP 列表有对端配置
4. skills 不会自动出现（仍需设置页手动恢复）
