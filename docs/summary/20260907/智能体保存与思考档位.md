# 智能体保存、思考档位与小杰补齐（v1.7.1）

## 问题

1. 智能体点「保存」无成功反馈（通讯录静默；资料抽屉直接关）。
2. 供应商只勾选部分思考档时，智能体编辑仍显示 none/low/high/max 全档。
3. Chat 格式 `none` 误用 `reasoningEffort: none`（DeepSeek 要求 `thinking.type=disabled`）。
4. 小杰能力边界不清；MCP 空态误导「让小杰配置」；缺解散群工具与 memory `scope` schema。
5. 同步记忆/skills 后需要整应用重启入口。

## 改动

| 项 | 做法 |
|----|------|
| 保存反馈 | `AgentEditor` 显示「✅ 已保存」；资料抽屉成功后延迟 600ms 再关 |
| 重启 Jeff | 菜单 / 托盘：`app.relaunch()` + `app.quit()` |
| 思考 UI | 下拉按模型 `thinkingTiers` 过滤；私聊初始 variant 用 agent.thinking |
| thinkingVariant | Chat none→disabled；强度带 enabled；Responses none→effort none；max 保留 |
| 小杰 | 指令与 usage skill 写清边界；MCP 空态改文案；`jeff_memory.scope`；`jeff_project_delete` |
