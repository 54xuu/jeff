# 聊天模型归属与智能体下拉样式（v1.7.2）

## 问题

1. 智能体资料里的「模型」下拉（`ModelPickerCombo`）边框用了未定义的 `--line`，且背景透明，与面板底色糊在一起，看不出可点。
2. 私聊 / 项目群输入栏仍可切换「模型」和「思考程度」，与产品心智不符：模型与思考应属于智能体自己的设置。

## 改动

| 项 | 做法 |
|----|------|
| 下拉样式 | `.combo-trigger` / `.combo-menu` 对齐 `.field select`：`var(--border)` + `var(--bg-list)` / `var(--bg-panel)` |
| 私聊 UI | 去掉可切换菜单；保留只读模型 chip，点击打开「资料」抽屉 |
| 项目群 UI | 去掉模型/思考选择；提示各成员用自己的设置 |
| 发送路径 | `PrivateChat` / `GroupChat` / 委派：以目标智能体 `model_*` + `thinking` 为准，忽略 IPC 覆盖；空 thinking 不传 variant |
| 测试 | `agentPromptOpts`、群聊路由模型、私聊模型归属；e2e 改断言 |
