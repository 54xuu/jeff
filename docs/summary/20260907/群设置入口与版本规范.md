# 群设置入口、CI 修复与版本规范

> 日期：2026-09-07 · 版本：v1.3.0 → **v1.4.0**

## 背景

1. 建群后没有微信式「群设置」；私聊顶栏也没有智能体资料入口。
2. GitHub Actions `Test & Release` 因 `McpProbeResult.elapsedMs` 缺失类型检查失败，并提示 Node 20 action runtime 弃用。
3. 需要仓库级 `AGENTS.md` 约定：bug → patch，功能/重构 → minor，完成后升级本机软件。

## 已完成

### 项目群设置（微信群资料）

[`GroupInfoDrawer.tsx`](../../apps/desktop/src/renderer/src/components/GroupInfoDrawer.tsx) 顶部增加「群设置」：

- 群名 / 图标 / 简介 / 工作空间目录（浏览）/ 群主
- 保存走已有 `IPC.projectSave`
- 成员区可「添加成员」；底部可「解散群」
- 任务看板仍在同抽屉下方

### 智能体资料抽屉

- 抽出共享 [`AgentEditor.tsx`](../../apps/desktop/src/renderer/src/components/AgentEditor.tsx)
- 私聊顶栏「资料」→ [`AgentProfileDrawer.tsx`](../../apps/desktop/src/renderer/src/components/AgentProfileDrawer.tsx)

### 小杰工具补齐

| 工具 | 新增字段 |
|------|----------|
| `jeff_project_create` / `update` | `workspace_dir` |
| `jeff_agent_create` / `update` | `thinking`（`''`/none/low/high/max） |

小杰指令与 `PROJECT_TOOL_HINT` 已同步说明。

### CI

- [`ipc.ts`](../../apps/desktop/src/main/ipc.ts) `mcpProbe` 映射补上 `elapsedMs`；停用映射为 `disabled`
- workflow：`actions/checkout@v5`、`actions/setup-node@v5`（Node 24 action runtime）
- 顺带：`sync/engine.ts` `timeoutMs` 收窄类型；skills 重入锁单测对齐「等待再执行」语义

### 规范与版本

- 新建根目录 [`AGENTS.md`](../../AGENTS.md)
- 三处 `package.json` + lock → **1.4.0**

## 本机升级

```bash
sudo dpkg -i /home/xujian/cdbox/jeff/apps/desktop/release/jeff-desktop_1.4.0_amd64.deb
```

安装后重启 Jeff，在「设置 → 关于」确认 **1.4.0**。

## 使用说明（用户侧）

- **改群**：打开项目群 →「群资料与任务」→ 顶部群设置保存；或跟小杰说「把某某群工作空间改成 …」
- **改智能体**：私聊顶栏「资料」，或「通讯录」页；也可让小杰 `jeff_agent_update`
