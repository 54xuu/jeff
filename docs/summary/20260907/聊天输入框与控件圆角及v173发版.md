# 聊天输入框与控件圆角及 v1.7.3 发版

## 需求与决策

- 聊天输入框增加清晰的顶部拖拽把手，私聊和项目群都可上下调整高度。
- 输入框高度限制为最小 40px、最大 320px，并同时受聊天窗口高度约 50% 的约束；高度在当前窗口组件实例内保留，不写入持久化设置。
- 输入框使用独立背景、边框、圆角和聚焦高亮，发送/停止按钮保持高对比度。
- 全应用按钮、输入框和其他用户可见控件保留原有视觉层级，统一改用圆角设计 token，不进行大规模 Button 组件重构。
- 版本从 1.7.2 升级到 1.7.3，Linux 本机安装新包，Windows 由 GitHub Actions 的 Windows runner 构建。

## 代码改动

- `apps/desktop/src/renderer/src/components/ChatShared.tsx`
  - 新增共享 `useComposerResize` hook。
  - 处理指针拖拽、窗口缩放约束、全局拖拽状态和组件卸载清理。
- `ChatWindow.tsx`、`GroupWindow.tsx`
  - 接入共享高度状态和 `chat-resize-handle` 顶部拖拽把手。
  - 保留原有发送、换行、图片粘贴/拖入、@成员补全和停止生成行为。
- `styles.css`
  - 补齐 `--radius-xs/sm/md/lg/pill` token，并将用户可见控件的大部分硬编码圆角改为 token。
  - 输入框增加边框、独立底色、聚焦高亮；拖拽中显示 ns-resize 光标和把手反馈。
  - 普通表单字段继续使用统一圆角，聊天 textarea 使用 `--input-h` 的最小高度。
- `apps/desktop/e2e/ui.spec.ts`
  - 增加私聊和群聊拖拽把手的显示及高度变化冒烟验证。
- 版本文件
  - 根目录、`packages/core`、`apps/desktop` 的 `package.json` 与 `package-lock.json` 已同步为 1.7.3。

## 安装与发布

- 本机安装目标：`sudo dpkg -i apps/desktop/release/jeff-desktop_1.7.3_amd64.deb`。
- 安装后退出并重新打开 Jeff，在“设置 → 关于”确认版本为 1.7.3，并用 `dpkg -s jeff-desktop` 辅助确认。
- 发布目标：提交后推送 `v1.7.3` tag，触发 `.github/workflows/release.yml` 的 Ubuntu/Windows 双平台构建。
- Linux 产物为 AppImage + deb；Windows 正式安装包为 CI 生成的 NSIS `.exe`，不把本机 `win-unpacked/Jeff.exe` 当作安装包。
- `release/`、`resources/oc-bin/`、`.tmp/` 等可执行产物、二进制和敏感文件不应加入 Git。
