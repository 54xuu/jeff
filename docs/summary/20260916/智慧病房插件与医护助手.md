## 三、本仓库改动

### 3.1 插件样例 [`examples/plugins/zhbf-night/plugin.json`](../../examples/plugins/zhbf-night/plugin.json)

- `mcp.url` → `http://192.168.3.249:4000/mcp`
- `homepage` → 公开大屏地址
- `commands`：`/zhbf`、`/入院`、`/出院`、`/危重`、`/labs`
- `tools` 声明：`board_home_overview`、`board_today_admissions`、`board_today_discharges`、`board_critical_patients`、`ward_overview`、`ward_labs`

### 3.2 [`packages/core/src/agents/registry.ts`](../../packages/core/src/agents/registry.ts)

`renderAgentMd`：若 `category === '智慧病房'` 或 `name === '医护助手'`，额外禁用 `bash` / `edit` / `write` / `patch` / `task` / `read`。

**原因（实测）**：MCP StreamableHTTP 曾因服务端 `notifications/initialized` 返回 500 连不上时，模型会用 bash 读 `jeff.db` 抠 token 再 curl MCP——答案碰巧对，但绕过了插件语义。禁掉文件/命令工具后，只能调 `plugin-zhbf-night_*`。

## 四、本机落地（真实 `~/.jeff`）

1. 备份 `jeff.db` → `jeff.db.bak-<timestamp>`
2. 用 `@jeff/core`（`PluginManager` + `agentRepo` + `AgentRegistry`）写入：
   - 插件目录 `~/.jeff/plugins/zhbf-night/`
   - 密钥 `plugin-secret:zhbf-night`（本地 kv，不同步）
   - 启用插件 → `settings:mcp` 注入 `plugin-zhbf-night`
   - 智能体 `agt_yihu_assistant`（医护助手 / 智慧病房 / `opencode-go/deepseek-flash` / thinking=high）
3. `syncNow` → WebDAV `ok:true`（Windows 端同步后可见智能体与插件目录）

临时脚本在 `.tmp/zhbf-mcp/`（gitignore，不提交）。

## 九、续写：单条英文指令 + 插件设置页（v1.8.9）

### 决策

- **改 Jeff 插件机制本身**（所有插件），不只改智慧病房样例。
- 每插件 **最多一条** `/` 快捷指令，name 须英文或拼音；靠 `prompt` 描述功能分流。
- 官网首页 **写回 `plugin.json`**（可同步）；密钥仍只存本机 kv。

### 改动摘要

| 面 | 内容 |
|---|---|
| `PluginManager.parseManifest` | `commands.length > 1` 报错；name 匹配 `/[a-zA-Z][a-zA-Z0-9_-]*` |
| `PluginManager.setHomepage` | 写回清单；空串清除 |
| 小杰工具 | 平铺 `command` / `command_prompt` / `command_description`（兼容旧 `commands` 数组） |
| 插件页 | 钥匙 → 齿轮「设置」：密钥 + homepage；IPC `plugin:saveSettings` |
| 样例 `zhbf-night` | 仅保留 `/zhbf`，prompt 写明双口径入院出院、危重、护理、检验等工具 |
| 文档 | 全局 `~/.agents/AGENTS.md`「Jeff 插件约定」+ `docs/plugins.md` + `XIAOJIE_INSTRUCTIONS` |
