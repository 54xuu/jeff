# 插件筹码输入框排版、气泡样式与用户气泡底色（v1.8.12）

> 日期：2026-09-16 ｜ 状态：已完成

## 一、问题

v1.8.11 选中 `/zhbf` 后有三处体验问题：

1. 输入框用左右两块 textarea 硬切，筹码右侧整列被「后段」占满，换行仍从筹码右边缩进，左边一大块不能点。
2. 暗色主题下，已发送气泡里插件中文名用亮蓝，贴在绿色底上又刺眼又没对齐（偏下）。
3. 用户气泡背景需要改成 `#35d28d`。

## 二、改动

- **输入框**：筹码叠在首行（只占自身宽度），正文 textarea 用 `text-indent` 给首行让位；换行 / 折行从对话框左边起排。退格在正文开头仍整块删筹码。`data-testid="chat-draft"` 保留。
- **气泡筹码**：绿色气泡内改为深墨绿胶囊 + `--bubble-plugin`（`#0b3d22`），`vertical-align: -0.15em` 与汉字对齐。
- **用户气泡**：亮/暗主题 `--bubble-user` 均为 `#35d28d`，正文 `--bubble-user-text: #0b2618`。历史记录里的用户消息同步。

## 三、测试

- `npm test`：277 passed / 17 skipped
- core / desktop `tsc` 通过
- mock UI E2E + v18：5 passed（含斜杠筹码可见、退格整块删除）
