# 忙碌状态、插件斜杠菜单与筹码（v1.8.11）

> 日期：2026-09-16 ｜ 分支：当前工作分支 ｜ 状态：已完成

## 一、目标

1. 智能体正在执行任务时，头像右上角显示忙碌绿点。
2. 修正 `/` 调用插件的方式与样式：分组菜单、选中后输入框/气泡用「图标 + 亮蓝中文名」筹码，发给模型的是短约束而不是工具分流长 prompt。
3. 所有引用插件的地方统一走 `PluginIcon`（SVG 优先）。

## 二、忙碌状态

- 判据：store 的 `sending` / `streaming`（含定时任务触发的生成）。
- 出现位置：左侧会话列表、当前会话顶栏、正在流式输出的助手头像；项目群在列表/顶栏打在群头像，对话里打在正在说话的成员头像。
- 智能体/通讯录管理页不显示。
- 样式：头像右上角约 8px 绿点，带背景描边、轻微呼吸。

## 三、插件 `/` 与筹码

- `/` 菜单按组渲染，这一轮只有「插件」组；每一行 `/{指令} {图标} {中文名} {简介}`；暗色主题指令/中文名用主文字色、简介灰色；上下键选择。
- 选中后 `/zhbf` 换成筹码，插在当时敲 `/` 的位置；一条消息最多一个，再选即替换；退格整块删除；只发筹码也允许；发出去后输入框清空。
- 发给模型：`请使用插件「…」（指令 /xx，MCP 前缀 plugin-{id}）回答下面的问题。只调用该插件提供的工具。` + 用户原话。不枚举 MCP 工具。
- 落库：用户消息正文编码为 `<!--jeff-plugin:{…}-->` + 短约束 + 用户原话；历史解码后气泡只显示筹码 + 原话。`plugin_id` 在渲染时优先用当前 `icon.svg`。
