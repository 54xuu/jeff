# 收起会话列表按钮换到列表右侧（v1.8.15）

## 现象

聊天界面「收起会话列表」功能本身没问题，但箭头出现在**左边**——导航栏与会话列表之间。第一眼会当成「收起左边的菜单栏」。

## 根因

三栏 flex 顺序写成了 `NavRail → PaneResizer → list-pane → 对话区`。分隔条零宽、热区跨在分栏线上，于是箭头正好贴在 64px 导航栏的右边缘。

`side="left"` 语义没问题：它表示「拖的是左栏」（往右拖变宽、箭头朝左表示收起列表）。错的是 DOM 位置。

## 修复

[`apps/desktop/src/renderer/src/App.tsx`](../../apps/desktop/src/renderer/src/App.tsx) 把 `PaneResizer` 挪到 `list-pane` **之后**：

```
NavRail → list-pane → PaneResizer → 对话区
```

收起后的展开细条本来就在对话区左边缘，不用动。

同版还带上工作区里未提交的私聊/定时任务 90 分钟超时修复（原先准备发 1.8.14），版本号 PATCH 到 1.8.15，避免本机已装 1.8.14 时无法确认新包。
