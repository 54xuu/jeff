# Jeff 拟人西瓜 SVG Logo 设计与输出

## 1. 背景与需求

用户希望为 Jeff 设计一个 SVG 格式的全新 Logo，保存到 `docs/assets` 目录下。
设计核心诉求：
- **角色形象**：“Jeff”是一个拟人的西瓜（Anthropomorphic Watermelon）
- **核心特征**：「绿色、可爱」
- **设计标准**：高品质纯矢量 SVG，兼具吉祥物亲和力与 App Icon / 品牌 Logo 的识别度，支持无损缩放并在深色与浅色背景下均表现出众。

## 2. 视觉设计拆解与实现

### 2.1 整体构图与造型
- **画幅与视口**：`viewBox="0 0 512 512"`，采用高精度纯矢量贝塞尔曲线绘制，适配 16px 至 1024px+ 任何分辨率。
- **身躯轮廓**：饱满圆润的微水滴/蛋形西瓜宝宝身躯，幼态比例，亲和力强。
- **绿色阶梯体系**：
  - 身体基底：从高光草绿色（`#a7f3d0`）过渡到鲜翠绿（`#22c55e`）与墨翠深绿（`#14532d`），立体饱满；
  - 西瓜条纹：两侧自然起伏包裹的 4 道墨绿经典西瓜纹（`#052e16` - `#166534`），中轴面部区域留白开阔，保证表情干净清爽；
  - 高光与反光：顶部月牙透亮高光与侧下缘微反射光，呈现果冻般的晶莹质感。

### 2.2 萌化面部与性格表现
- **水灵大眼睛**：采用动漫大眼比例，深黑绿色眼瞳底部衬托翡翠绿（`#10b981`）虹膜微光，双重高光（大主光 + 小副光 + 星点微光），神采奕奕、充满关怀；
- **粉嫩腮红**：柔和羽化的珊瑚西瓜粉腮红（`#fb7185`），带有日系高光斜线条纹；
- **快乐笑脸**：开怀的猫猫唇微笑（Open Smile），露出粉红色的甜美西瓜小舌头（`#fb7185`），笑容极具感染力。

### 2.3 西瓜特征与互动细节
- **生机瓜藤与双叶**：头顶有一根俏皮螺旋卷曲的小藤蔓与两片舒展的西瓜嫩叶，带有清晰叶脉与嫩绿高光；
- **手捧西瓜切片**：两只胖乎乎的小肉手捧着一弯月牙状的西瓜切片，清晰展现深绿瓜皮、嫩白瓜瓤、晶莹红肉（`#f43f5e`）与四颗带水滴高光的小瓜籽，点题西瓜本体；
- **小短脚与接触阴影**：身体下方露出两只圆圆的小短脚，踏在柔和的半透明椭圆阴影上，重心扎实稳定；
- **灵动星芒**：右上方漂浮代表 Jeff AI 机敏与灵感的金色星芒，突出智能体陪伴属性。

- 使用 `cairosvg` 分别在透明底和纯白底（`-b '#ffffff'`）下进行了像素级光影与表情审查；
- 去除条纹穿过面部的干扰，确保额头清爽、眉眼舒展、红绿对比鲜亮抓眼；
- 产物符合规范并妥善放置在 `docs/assets/` 目录下。
