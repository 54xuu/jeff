# 标题显示版本号与密码库

日期：2026-10-10  
版本：2.2.4

## 做了什么

- 原生窗口标题改为 `Jeff v<APP_VERSION>`，并拦住页面标题覆盖。设置 → 关于仍保留版本说明。
- 新增设置 → 密码。变量用系统钥匙串加密；钥匙串不可用（含 Linux `basic_text`）时明文保存，并在页面标明。已启用的条目在引擎启动时注入，并覆盖系统同名变量。保留名不能写入。
- 值不进 WebDAV。同步只带变量名、备注、启用状态和删除墓碑；另一台电脑显示「待填写」。
- 改完不自动重启。页面提示「立即重启引擎」，有进行中的工作时先确认。
- 没有模型工具可以读写密码。聊天记录、调试日志和 sidecar 日志会替换长度不少于 8 的精确值。
- 手机遥控对 `secrets:*` 和 `debug:sidecarEnvKeys` 一律拒绝。Android 本次没有密码管理界面。
