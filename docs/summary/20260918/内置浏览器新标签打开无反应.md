# 内置浏览器新标签打开无反应

## 问题

内置浏览器里点击「在新标签打开」的链接（`target="_blank"` 或 `window.open(url)`）没有任何反应。

## 原因

Electron 39 已移除 `<webview>` 的 `new-window` 事件。webview 默认禁止弹窗（需要 `allowpopups`），且新窗口拦截必须在主进程通过 `did-attach-webview` 拿到 guest `webContents` 后调用 `setWindowOpenHandler`。原先两处都没做，Chromium 把新窗口请求静默吞掉。

主窗口自己的弹窗已经用 `setWindowOpenHandler` + `shell.openExternal` 处理过，但不覆盖 webview guest 页面。

## 改动

- 渲染层 webview 加上 `allowpopups`，让 guest 能发出新窗口请求。
- 主进程在 `did-attach-webview` 里对 guest 挂 `setWindowOpenHandler`：合法 `http(s)` 地址在当前 webview 原地 `loadURL`，一律 `deny` 真正的新窗口。空地址 / 非 http(s) 忽略。
- 不做多标签页 UI（与用户确认的最小修复一致）。
- `docs/built-in-browser.md` 同步描述：新窗口请求在当前页打开，页面权限请求仍默认拒绝。
- E2E：测试站首页加 `#blank-link`（`target="_blank"` 指向 `/wizard`），`v18.spec.ts` 用 `jeff_browser_click` 点它，断言当前页变成向导页。

## 版本

`1.8.18` → `1.8.19`（PATCH：修已有内置浏览器行为缺陷）。
