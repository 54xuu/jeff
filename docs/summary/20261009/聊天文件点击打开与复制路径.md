# 聊天文件点击打开与复制路径

## 目标

聊天里出现的真实文件可以点击打开，右键可以打开、在文件夹中显示或复制解析后的绝对路径。不存在的路径保持纯文本。可执行文件不直接运行，改为在文件夹中显示并提示。手机端共用识别逻辑：Markdown 可预览，其它文件提示到电脑查看，长按复制电脑上的路径。

## 实现

- 路径识别放在 `packages/core/src/files/linkify.ts`，桌面和手机共用。覆盖绝对路径、`~/`、Windows 盘符、`file://`、相对路径、纯文件名，以及行内代码、Markdown 链接和图片里的路径。带空格的路径只在引号、反引号或链接括号里识别。
- 存在性校验在消息渲染完成后批量走 `fs:resolvePaths`。流式输出过程中不校验。解析顺序是绝对路径和 `~/`、会话工作区精确拼接、全局工作区精确拼接，然后在工作区内有限搜索（深度 5、最多 5000 项，跳过 `node_modules`、`.git` 和点目录；同名取最近修改）。相对路径和符号链接不能逃出工作区；已经存在的绝对路径可以在工作区外。
- 桌面点击：`.md` 打开内置预览，其它文件交给系统默认程序，失败则在文件夹中显示，目录直接打开。`exe`、`bat`、`cmd`、`com`、`scr`、`ps1`、`sh`、`bash`、`zsh`、`app`、`msi`、`dll`、`so`、`dylib` 只显示所在文件夹并提示不会直接运行。
- 右键菜单沿用聊天行菜单样式，三项为打开、在文件夹中显示、复制路径。复制的是解析后的绝对路径。
- 手机通过同一 IPC 在电脑上解析。`fs:resolvePaths` 归类为远程放行；`fs:openPath` 仍是远程替换，手机不能启动电脑上的程序。
- 版本先到 `2.2.1`。已安装的 `2.2.1` 在 Windows 上右键后菜单会被随后的按下事件关掉，所以看起来没有菜单。`2.2.2` 改为等这次右键结束再响应外部点击，并在主进程拦住文件链接的系统右键菜单。
