# 内置浏览器接管与采集优化方案

日期：2026-10-08。状态：方案已修订，待用户确认执行；产品尚未实现。

## 结果

按用户要求搜索 ChatGPT / Codex 官方功能，调用 `grill-me`（转调 `grilling`）逐题确认七项需求。根据最新指示，借鉴功能仅保留内置浏览器相关内容，通用目标模式、活动中心、消息排队/纠偏、侧聊、事件触发任务与系统窗口捕获等移出本方案，暂不实现。

完整技术与验收方案：[Jeff 内置浏览器接管与采集稳定性方案](../../notes/20261008-ChatGPT-Codex功能借鉴与浏览器接管方案.md)。

## 确认范围

- 本期：人工接管闭环、稳定元素定位、动态加载等待。
- AI 可请求接管，用户也可主动接管；接管时暂停原任务，并阻止所有 Agent 通过 Jeff 浏览器接口读取、截图或操作页面。其他非浏览器会话继续。
- 单浏览器按任务独占，其他浏览器任务等待，用户可主动切换。
- 等待状态跨退出与重启保留，只由用户明确继续；恢复前检查当前页面，不重放旧提交。
- 复用本机登录会话，优先扫码，不新增密码保存与凭据同步。
- Android 配套显示状态、网站、原任务和提醒，支持返回原会话与取消；实际网页操作在桌面。
- 下载管理、多标签、站点数据管理、网页反馈、连接现有浏览器及认证弹窗兼容仅为后续浏览器候选，不纳入本期。

## 技术要点

- 主进程维护运行归属、控制权、请求与页面代次；保护 CDP 截图等真实入口，拒绝旧请求及晚到结果。
- 引擎暂停与任务持久等待区分于正常完成、取消和失败，避免群主提前总结、定时运行误报成功或重复触发。
- 稳定元素引用绑定当前页面与 DOM 节点；歧义拒绝、过期重读。动态等待按目标条件且有超时，接管或取消立即停止。
- 人工认证输入不进入模型工具参数、页面回传、日志或截图；登录会话仅在本机复用。
- 任务/引擎/定时模块的改动仅服务浏览器接管，不新增对应的通用产品能力。
