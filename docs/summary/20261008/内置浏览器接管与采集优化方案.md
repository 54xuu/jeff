# 内置浏览器接管与采集优化

日期：2026-10-09。状态：完成。按用户修订范围完成代码、测试、三平台正式构建，以及 Ubuntu、Windows、Android 安装验收。

## 本期范围

用户将 ChatGPT / Codex 借鉴功能限定为内置浏览器相关能力，本期只交付浏览器接管、稳定元素定位和动态内容等待。没有实现其他产品方向。

- AI 可请求接管，用户也可主动接管；控制交接后暂停原运行，并封锁 AI 经 Jeff 浏览器工具读取、截图和操作页面。
- 一个任务持有浏览器时，其它浏览器任务等待；可优先切换等待项。无关会话继续工作。
- 等待用户状态写入本机数据库，应用重启后保持等待，需用户明确交还 AI 或取消；续接时先检查当前页面，提示不重复执行外部副作用。
- 复用桌面内置浏览器的本机持久分区，不保存或同步密码。Android 显示状态和提醒、可打开原会话或取消；网页仍在桌面操作。
- 增加当前页面元素引用、歧义拒绝/引用失效保护，以及等待元素出现、消失、可见或可操作的工具。
- 对认证字段和 URL 凭据做回传保护；用户接管期间停止页面错误采集。

## 技术落点

核心通过单条本机 `browser:handoff` 记录保存任务、会话、来源、站点、安全 URL 和等待状态；浏览器控制器维护独占者。AI 请求接管或用户点击接管时先写等待态、切换页面控制权、取消在途浏览器动作并中止原 OpenCode 回合。交还后向原会话注入续接指令，要求重新读取当前页面，并禁止模型重放已发出的点击、提交或上传。项目任务和定时任务的等待状态会进入各自运行记录。Android 的“打开原会话”会在桌面内部激活精确的私聊 session 或群话题；session ID 不通过远程 IPC 返回。

AI 浏览器工具经过会话身份校验；排队会话在获得浏览器前等待。当前排队列表在运行时内存中，等待用户的接管记录则跨重启保存。桌面工具栏显示接管任务、网站和状态；Android 只接收脱敏状态并提供定位原会话、取消和提醒。

稳定定位使用本轮页面观察生成的 `element_ref`，导航或节点替换后失效；CSS/文本定位遇到多个匹配项时拒绝猜测。`jeff_browser_wait_for` 支持有限时长的条件等待，任务取消或接管时停止轮询。

## 尚未覆盖的验收边界

用户没有指定真实采集网站，因此没有验证真实站点扫码、跨域认证弹窗或站点策略兼容。真实模型闭环仅覆盖 OpenCode（Jeff）；其他执行引擎以及真实项目群/定时任务链路未做模型级验收。浏览器排队项不跨进程重启保存。这些限制不影响已通过的本地测试站和具名安装验收。
