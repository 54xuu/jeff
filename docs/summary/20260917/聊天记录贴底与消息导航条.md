# 聊天记录贴底与消息导航条

## 问题

1. 进入已有会话时，右侧对话记录总是停在最顶部，需要手动滑到底部才能看到最新消息。
2. 长对话缺少快速跳转入口，找不到某条历史消息只能一直滚。

## 原因

`useAutoScroll` 在挂载时立刻按当时的 `scrollTop` 判断「是否贴底」。切换会话会整窗重挂载；若历史已在 store 缓存，首屏就是 `scrollTop=0` + 内容铺满，会被误判成「用户在翻历史」，后续再也不会自动滚到底部。

## 改动

- `useAutoScroll` 挂载时用 `useLayoutEffect` **强制贴底**，再开始正常的贴底跟随；用户上翻后仍不抢滚动。
- 私聊 / 群聊左侧增加垂直居中的消息导航条：一根小长方形对应一条消息，悬浮 Popover 预览前 100 字，点击跳转到该消息并短暂高亮。
- 流式中的临时气泡不进导航条，落库后才出现。
