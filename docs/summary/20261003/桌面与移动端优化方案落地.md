## 1. 省 Token（方案第 2 节，全部完成）

### 2.2 稳定 System Prompt 前缀（SUBTASK_STEER 不再动态增删）

- 原状：用户消息命中「独立/分开处理」触发词时才把 `SUBTASK_STEER` 拼到 system 尾部，下一轮又移除——触发轮整段对话历史在供应商侧**无缓存重发**（Prompt Caching 是严格前缀匹配），长对话反而贵。
- 改法：`SUBTASK_STEER` 文案改写为**中性条件式**（「当用户明确要求独立处理时……用户没提就忽略本节」），对非内置智能体**固定拼接**在 system 末尾；`withSubtaskSteer(system, { builtin })` 去掉 text 参数（`packages/core/src/orchestrator/subtask.ts`，调用点 private.ts / group.ts）。小杰没有 `jeff_spawn_subtask` 工具，照旧不注入。
- 回归：`subtask.test.ts` 断言重写（非内置恒拼接、builtin 原样、前缀稳定性=KV-Cache 命中的前提）；真模型 live20-R3 证明新文案仍正确驱动「每个文件独立处理 → 逐文件派生子任务落盘」。

### 2.3 联网指南按能力注入（WEB_SEARCH_GUIDE 条件化）

- 原状：`buildMemorySystem` 给每一轮私聊/群聊/定时任务都注入约 110 token 的联网指南，**本机根本没装 `byted-web-search` 技能**——指南指向一个不存在的对象，纯烧 token。
- 改法：新增 `agentWebSearchCapable(agent)`（`packages/core/src/index.ts`）：skill 工具被禁用、或技能目录（`~/.agents/skills/byted-web-search/SKILL.md`，经 `JEFF_SKILLS_DIR` 可覆写）不存在 → 不注入。子任务会话维持剥离（上一会话已做）。为复用同一份工具面事实，从 `renderAgentMd` 抽出 `agentDeniedTools()`（registry.ts）。
- 单测 `web-guide.test.ts`；真模型 live20-R1 断言：有用户级 AGENTS.md 记忆块时 system 不含联网指南（排除「整体为空」假阳性）。

## 2. 功能优化（第 3 节）

- **F-1 移动端上下文用量 + 一键压缩**：聊天顶栏标题旁徽标（`12k/128k`，85% 警告/超线红色），点开面板显示进度条、自动压缩线、已压缩条数与「一键压缩」按钮；数据走 `context:preview`/`context:compress`（远程白名单默认放行，群聊看群主会话）。进会话/每回合结束/压缩后自动刷新。
- **F-2 移动端 `/` 快捷指令**：输入 `/` 在 composer 上方弹出 pills（已启用插件的指令按前缀过滤 + `/压缩上下文`、`/新会话` 两个固定动作）；点插件指令挂成筹码随消息发送（`chatSend`/`groupSend` 的 `plugin` 字段，桌面 IPC 原生支持）；消息流里把桌面端发的 `<!--jeff-plugin:...-->` 头解码成筹码 + 原话（`decodePluginUserMessage`）。
- **F-3 桌面端文本文件拖拽**（上一会话已做）：`.txt/.md/.json/...` 拖进聊天注入代码块上下文（单文件 64KB 截断保护）。

## 6. 踩坑记录

1. **`context:preview.system` 不含子任务规范**：STEER 是发送时在 `sendMessage` 参数上拼接的，预览只反映 `buildMemorySystem`——live20-R1 第一版断言打错了地方，按「先分清谁的锅」原则改测断言而非产品代码。
2. **seed 显式配了 128k**：live20 home 的供应商配置带 `limit.context: 128000`，兜底分支不该触发；2.4 的兜底改用单测覆盖（显式优先是正确语义）。
3. **移动端代码高亮嵌套 `<code>`**：react-markdown 的 `pre` children 本身就是 `<code>` 元素，再包一层会 strict-mode 撞出两个 code；桌面端是直接渲染 `preProps.children`，移动端对齐。
4. **指令盘 Esc 竞态**：input 聚焦走 rAF，偶发慢于按键导致 Escape 丢失；Esc 处理上移到 open 期间的 document 级监听（符合「消费 Esc 必 preventDefault」的仓库约定）。
