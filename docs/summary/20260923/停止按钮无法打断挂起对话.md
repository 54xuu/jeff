# 停止按钮无法打断挂起对话

## 现象

私聊里一轮生成停在「。。。」，右下角停止按钮点了没有反应。`debug-20260923.log` 里会话 `ses_f329f3b54ffeQoK8MR3UFcRQ3A`（智能体 `agt_dCyaS3KjK_vH`，模型 `xiaomimimo / mimo-v2.6-flash`）从 16:28 开始，16:51:37 写文件成功后不再有任何流式输出。17:33 起多次 `abort` + `chat-stop-req`，每次都跟着 `stream-done`，界面的发送中状态却不结束。

## 原因

两件事叠在一起：

1. **停止只通知了引擎，没有掐断本机正在等的请求。** `sendMessage` 的 `POST /session/:id/message` 会一直阻塞到整轮结束，总预算 90 分钟，而且 Undici 的 headers/body 超时是关掉的。模型在工具步之后不再吐 token 时，这个 POST 就挂住。`POST /abort` 返回成功，也只会让 SSE 打出 `stream-done`（清掉流式气泡）。界面的「。。。」看的是 `sending`，要等这次 `send` 的 Promise 结束才清。引擎没有把卡住的模型调用解开，Promise 就一直挂到 90 分钟。
2. **引擎在私聊还在跑时被重启，停止打到了新客户端。** 17:08:55 项目群流水线空闲，触发了推迟的 sidecar 重启（`restartIfRegistryDirty`）。重启只躲开了群任务，没有躲开私聊的在途 `sendMessage`。旧客户端被换掉后，那次 POST 还挂在旧连接上；之后的停止打到新端口的新 `OcClient`，旧请求收不到。

## 修复（1.8.27）

- `abortSession` 先取消本机会话上的在途 `sendMessage`，再 `POST /abort`。停止按钮几毫秒内就能让界面退出「。。。」。
- 引擎换代时 `cancelInflight`：旧客户端上所有在途发送立刻失败，文案不含 `abort`，界面显示「引擎刚刚重启，进行中的对话已中断，请再发一次」，而不是继续转圈。
- 有在途 `sendMessage`（含私聊）时推迟 sidecar 重启，等这轮结束再重启。
