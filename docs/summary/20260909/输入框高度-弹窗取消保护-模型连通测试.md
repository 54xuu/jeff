# 输入框高度、弹窗取消保护、模型连通测试（v1.7.14）

- 日期：2026-09-09
- 版本：1.7.14（PATCH，三处 package.json 已同步）
- 类型：UI/UX 改进 + 新增设置页探测能力

## 问题与需求

1. 聊天对话输入框默认高度太矮（40px），需要改为原来的 3 倍（120px）。
2. 所有弹出框点外部/失去焦点即消失，录入的数据全部丢失；要求弹出框必须有【取消】按钮（或右上角 ×），防止误关丢数据。
3. 模型供应商设置页的模型列表右侧需要【测试】按钮，验证模型是否连通。

## 方案与实现

### 1. 输入框默认高度 120px

- `apps/desktop/src/renderer/src/components/ChatShared.tsx`：新增 `COMPOSER_DEFAULT_HEIGHT = 120`，`useComposerResize` 初始 state 改用它。
- 拖拽范围维持 40–320px 不变（用户仍可拖回矮输入框），不做持久化（决策：只改默认值）。
- 私聊（ChatWindow）与群聊（GroupWindow）共用该 hook，一处改动同时生效。

### 2. 重型弹窗「取消/关闭」保护（脏检查确认）

新增共享 hook `apps/desktop/src/renderer/src/components/ui/useDirtyClose.tsx`：

- `useDirtyClose({ dirty, onClose, disabled? })` 返回 `requestClose()` 与 `guard`（确认框）。
- dirty 时点遮罩/Esc/取消/× → 弹「放弃未保存的修改？」确认框（复用现有 `ui/Dialog`，文案：放弃修改 / 继续编辑）；不脏 → 直接关。
- Esc 约定：其他「消费 Esc」的组件（emoji 选择器 `useDismissable`、`ModelPickerCombo`、行内改名输入框）处理 Escape 时调用 `e.preventDefault()`，本 hook 检测 `defaultPrevented` 即跳过，避免一次 Esc 连关两层。

逐文件改造：

| 弹窗/抽屉 | 改动 |
|---|---|
| `CreateGroupModal.tsx`（建群） | 加右上角 ×；遮罩/Esc/取消走脏检查（任一字段非初始值即脏） |
| `ProviderSettings.tsx` 的 `AddProvider` / `ModelForm` | 各加 ×；遮罩/Esc/取消走脏检查 |
| `McpSettings.tsx` 的 `ImportJson` | 加 ×；JSON 非空即脏 |
| `AgentProfileDrawer.tsx` + `AgentEditor.tsx` | AgentEditor 新增 `onDirtyChange` 上报脏状态；抽屉遮罩/✕/Esc/编辑器取消按钮走脏检查 |
| `GroupInfoDrawer.tsx`（群资料） | 群设置表单脏检查（成员增删是即时保存，不参与）；「添加成员」弹窗打开时挂起本层 Esc（`disabled`），并为其补 Esc 关闭 |
| `ChatHistoryDrawer.tsx` / `ContextDrawer.tsx`（浏览型） | 补 Esc 关闭（无表单直接关）；聊天记录行内改名的 Esc 已 preventDefault 不会误关抽屉 |

- 轻量浮层（emoji 选择器、模型下拉、@补全、+菜单）与原生 confirm/alert、Toast 维持现状。
- `MemorySettings.tsx`（AGENTS.md 编辑器）此前已自行实现脏检查，保持不动；新 hook 的确认框文案与交互与其对齐。
- `styles.css` 新增 `.modal-title-row`（标题行 + 右上角 × 布局）。

### 3. 模型连通「测试」按钮（主进程直连探测）

- 新增 `packages/core/src/providers/probe.ts`：`probeProviderModel(provider, modelId, timeoutMs=15000, skipTlsVerify)`，仿 `mcp/probe.ts` 模式（直连、独立超时、返回 `ok/error/elapsedMs`）：
  - `chat`：`POST {baseURL}/chat/completions`，Bearer key，`{model, messages:[…], max_tokens:1}`
  - `responses`：`POST {baseURL}/responses`，`{model, input, max_output_tokens:1}`
  - `anthropic`：baseURL 缺省 `https://api.anthropic.com`，`POST /v1/messages`，`x-api-key` + `anthropic-version` 头
  - HTTP 2xx 即 ok；错误提取 `error.message`/`message` 截断 200 字；超时给可读文案；遵循设置里的「跳过证书校验」（llmTls，宽松 undici Agent）。
  - 关键决策：探测用**传入的当前编辑态配置**，未保存的草稿也能测；不依赖 sidecar 重启。
- IPC 接线：`contract.ts` 新增 `providersProbe: 'providers:probe'` + `ProviderProbeResult`；`apps/desktop/src/main/ipc.ts` 加 handler；`packages/core/src/index.ts` 暴露 `probeProvider()`（读取 llmTls 设置）与模块导出。
- UI（`ProviderSettings.tsx`）：模型行右侧新增「测试」按钮（测试中禁用并显示「测试中…」）；结果以 tag 展示「已连接 · xxx ms」或「失败」，失败原因在行内红字展示；供应商配置一有改动即清空旧探测结果（防误导）。
