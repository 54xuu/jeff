| `https://opencode.ai/zen/go/v1`（go 套餐） | 真实 `~/.jeff/jeff.db` 的 `settings:providers` | **qwen3.7-plus、deepseek-v4-pro、kimi-k2.6 全在**（共 37 个模型） | ✅ 采用 |

## 发现并修复的 bug

### #1 备份完成弹窗显示「共 ？ 个文件」（v1.7.27 引入的回归）

- **现象**：点「立即备份 skills」，弹窗显示 `共 ? 个文件`，但设置面板「上次备份」里数字正常。
- **根因**：`packages/core/src/sync/engine.ts` 的 `backupSkills()` 把 `fileCount/elapsedMs` 只写进了 kv 的 `last` 副本，**返回给 IPC 的 report 对象上没有**——弹窗用的是 IPC 立即返回值，重进设置页才从 kv 读到数字。
- **修复**：返回前把 `fileCount/elapsedMs` 同时挂到返回值上（engine.ts `backupSkills` 收尾处）。
- **回归**：189 个单测全绿（含 version 一致性）、typecheck 仅 3 个存量 e2e helper 报错（AGENTS.md 记录在案）、mock UI E2E 全绿、live9 R1-R4 重跑全绿。

### 测试脚本侧的两个坑（非产品 bug）

1. sealos WebDAV 对 `Depth: infinity`（webdav 库 `deep: true`）PROPFIND 直接 403，测试对账脚本须逐目录 Depth 1 递归（与引擎实现一致）。
2. `group:history` 返回的消息里发送者字段是 `meta.agentId` + `sender_name`，不存在 `sender_id` 字段。
