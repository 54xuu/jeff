# 「联合会诊」群演示操作手册（基于附录A·北大人民医院 MDT 案例）

> 配套文档：[联合会诊项目群与十轮实测](./联合会诊项目群与十轮实测.md)
> 适用版本：Jeff v1.7.28+；群已写入本机真实数据，重启 Jeff 即可使用。

## 群里的三条基本规则（演示前先记住）

1. **默认群主处理**：在群里发言，消息默认由群主王建六接；要直接点名某位医生，用 `@成员名` 开头。
2. **一次一事**：每条消息只安排一件事（发起会诊 / 追加意见 / 写文件），等上一回合完全结束（发送按钮变回来、不再有医生在输出）再发下一条。
3. **模型分工**：王建六、营养科孙主任走 qwen3.7-plus；心内科、胸外科走 deepseek-v4-pro；内分泌科、放射科走 kimi-k2.6——演示时可以顺口介绍"六位医生三个模型，各科各脑"。

## 第 0 步：准备工作区素材（一次性）

群工作空间是 `~/jeff-workspaces/联合会诊`，里面已预置 `病例资料.md`（小李病例）。演示前可以打开给观众看一眼，会诊时医生们会真的去读它。

```markdown
# 门诊 MDT 会诊申请（患者：小李）
- 基本信息：28 岁女性，外地来京
- 主诊断：早期子宫内膜癌（病理已确认）
- 合并症：肥胖（BMI 31）、2 型糖尿病、高脂血症、高胆固醇血症、高尿酸血症
- 核心诉求：治疗肿瘤的同时保留生育功能
```

## 第 1 步：发起会诊（开场白，照抄即可）

在「联合会诊」群里发送：

> 请组织一次多学科联合会诊（MDT）。患者小李，28 岁女性，早期子宫内膜癌，合并肥胖（BMI 31）、2 型糖尿病、高脂血症、高尿酸血症，核心诉求是治疗肿瘤同时保留生育功能。工作空间里有《病例资料.md》可参考。请依次征求心内科、内分泌科、胸外科、放射科、营养科各位专家的意见，最后给出综合会诊意见与诊疗方案。

**你会看到**（实测约 2~3 分钟）：

1. 王建六先回复：病情概要 + 会诊目标，然后一次性 `@` 全部五位专家；
2. 五位专家按顺序依次发言，每人一小段本科室意见（心内科讲围术期风险分层、内分泌科讲胰岛素方案与血糖目标、胸外科讲手术指征、放射科讲 MRI/CT 检查顺序、营养科讲体重与膳食）；
3. 王建六最后输出「综合会诊意见」：诊断评估 + 诊疗路径 + 生育功能保护策略 + 随访计划表。

> 这一步就是宣传的主打画面：一条消息，六个医生各司其职，最后一锤定音。

## 第 2 步：追问某一位医生（演示 @直达）

等第 1 步回合结束后，点名追问：

> @内分泌科陈主任 患者术后血糖如果持续高于 10 mmol/L，方案要怎么调？

**你会看到**：只有陈主任接话，其他人不打岔——展示"群里点名，专家直达"。

## 第 3 步：派生任务——把意见落成文件（演示真干活）

> 请安排营养科孙主任，把针对小李的「会诊后饮食与代谢管理建议」整理成 Markdown 文件保存到工作空间，文件名「饮食建议.md」，写完后汇报。

**你会看到**：王建六派发 → 孙主任用工具真实写出 `~/jeff-workspaces/联合会诊/饮食建议.md`（含体重管理目标、膳食原则、血糖血脂协同改善）→ 汇报 → 王建六总结。演示完可以当场打开文件给观众看。

## 第 4 步（备选）：换附录A第二个病例——老刘的支气管异物

想展示第二个真实案例（呼吸与危重症 → 胸外科/放射科联动），可以新建发言：

> 发起第二例 MDT 会诊：老刘，左肺上叶尖段远端支气管内异物，长期咳嗽多年当地未确诊。请放射科赵主任评估异物定位方案，胸外科李剑锋评估手术风险与取异物术式，其他专家补充围手术期注意事项，最后给出综合意见。

> 注：本群固定六学科阵容，与附录A里呼吸与危重症医学科高占成教授团队的角色对应关系可在口播中说明："同样的模式，换一组科室就是另一场会诊"。

## 第 5 步：演示收尾话术（对着屏幕总结）

- "患者只发了一条消息，不用再跑五个科室挂号——群主自动拆解、五位专家并行会诊、群主汇总方案，这就是把附录A里北大人民医院的 MDT 搬进了 Jeff。"
- "每位医生背后是不同的大模型：qwen3.7-plus、deepseek-v4-pro、kimi-k2.6，各科有各科的'脑'。"
- "会诊意见不是聊天记录，是能落盘的文件——饮食建议已经躺在工作空间里。"

## 常见问题预案

| 状况 | 处理 |
|---|---|
| 某位医生回复太长/跑题 | 补一句「@该医生 请控制在 150 字以内，只给本科室意见」 |
| 回合迟迟不结束 | 群聊是串行驱动（一位说完轮下一位），六人全流程 2~3 分钟属正常，不要中途再发消息 |
| 想重新演示一遍 | 把第 1 步话术原样再发一次即可；或新开会话避免上下文干扰 |
| 提到工作空间文件医生说找不到 | 确认文件在 `~/jeff-workspaces/联合会诊`（群资料抽屉里可见工作空间路径） |
